# Underfoot

An ant-colony game inspired by SimAnt: you are the mind of the colony, one body at a time. Phone-first, portrait. A backyard of 70 regions in a PS1-style 3D look; daughter colonies, guardians, the wild bosses at the yard's edges, and (next) the house.

## Where things are
