# Archive

Frozen reference material from before the game in `game/`. Nothing here is built or loaded by the game.

- **`prototype/`**: build 6 as handed off (Oct 26): a single HTML page with a DOM-free `sim.js`, the ancestor of `game/src/sim/`. Open `prototype/underfoot-poc.html`. Rebuild it with `cat page-head.html sim.js app.js page-tail.html > underfoot-poc.html`; smoke-test with `node archive/prototype/smoke-test.js`.
- **`art-direction-3d/`**: the Three.js style mockups that chose the PS1 look. Open `art-direction-3d/index.html`.
- **`art-direction/`**: the earlier 2D mockups from `docs/UNDERFOOT_STYLE_BRIEF.md` (set aside).
