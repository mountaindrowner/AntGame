# Underfoot models

Every model in the game as a standalone binary glTF (`.glb`), written by `node scripts/export-models.mjs` from the code that makes them (`src/render/models/`). Open them in Blender (File → Import → glTF) or any glTF viewer. Colours are vertex colours (`COLOR_0`). See them all turning in the gallery: `npm run gallery`.
